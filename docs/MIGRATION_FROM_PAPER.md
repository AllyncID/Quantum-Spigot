# Evaluating migration from Paper

Quantum inherits Purpur's behavior and configuration as well as Paper's API.
Review Purpur settings when comparing against a Paper installation. Stop and
back up the server, then test a copy using the same Minecraft 26.2 version and
Java 25. Existing Bukkit, Spigot and Paper configuration stays in place.

Follow MIGRATION_FROM_PURPUR.md for the test workflow. No claim is made that
the external plugin compatibility matrix or persistence stress suite is
complete. Do not use a live production world as a benchmark fixture.
